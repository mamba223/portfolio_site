# Software & Systems Engineering Portfolio

A modern, responsive, high-performance portfolio website built with semantic HTML5, modern vanilla CSS, and vanilla JavaScript. Features a dark engineering-grade aesthetic, rich interactive project directory, live search & filtering, modal details, and accessible design.

## Features

- **Engineering Aesthetic**: Clean dark mode inspired by developer tools and systems interfaces.
- **Projects Showcase**: Detailed project directory covering distributed systems, AI/ML pipelines, full-stack applications, and utilities.
- **Live Search & Filter**: Real-time filtering by category (Systems, AI/ML, Full-Stack, Tools) and search keywords.
- **Responsive & Accessible**: Optimized for mobile, tablet, and desktop viewports with accessible markup and keyboard navigation.
- **Fast & Lightweight**: Pure HTML, CSS, and JS with zero framework overhead.

## Getting Started

To run the site locally:

1. Clone this repository:
   ```bash
   git clone <repository-url>
   cd portfolio-site
   ```

2. Open `index.html` in your browser:
   - Double click `index.html`, or
   - Use a local dev server (e.g. VS Code Live Server, `npx serve`, or `python -m http.server 3000`).

## Deployment

Deployable to any static hosting provider:
- **GitHub Pages**: Push to `main` and enable GitHub Pages under repository settings (`Settings -> Pages -> Deploy from branch`).
- **Vercel / Netlify / Cloudflare Pages**: Connect your GitHub repository and set the publish directory to `/`.
